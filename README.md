## ✨ What is HISAAB?

**HISAAB** — Hindi for *Accounting* — is a personal finance app built to make everyday money management simple and visual.

It brings expenses, budgets, bills, milk tracking, reports, insights, categories, and backup into one place.

---

## 🚀 Features

|     | Feature                |                                                     |
| --- | ---------------------- | --------------------------------------------------- |
| 💳  | **Expense Tracking**   | Record, categorize, edit, and review expenses.      |
| 🎯  | **Budget Management**  | Set monthly budgets and track remaining money.      |
| 📊  | **Insights & Reports** | Understand spending trends and financial activity.  |
| 🥛  | **Milk Tracking**      | Calendar-based milk delivery and payment tracking.  |
| ⚡   | **Bill Management**    | Track electricity and recurring household expenses. |
| 🏷️ | **Categories**         | Create, edit, and manage expense categories.        |
| 💾  | **Backup & Restore**   | Keep your financial records backed up safely.       |
| 🌙  | **Dark Mode**          | Modern light and dark themes.                       |

## ⚡ Quick Start

```bash
git clone https://github.com/DEVS-shakti/HISAAB.git
```

Open the project in **Android Studio**, let Gradle sync, and run the `app` module on an Android device or emulator.

**Minimum Android:** API 24 (Android 7.0)
