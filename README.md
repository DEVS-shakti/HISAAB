## ✨ Overview

**HISAAB** (Hindi for *Accounting*) is a personal finance management application designed to make everyday money management simple, organized, and insightful.

Instead of keeping financial records scattered across notes or spreadsheets, HISAAB brings **income, expenses, utility tracking, analytics, and reports** together in one intuitive interface. It is specifically optimized for the Indian household ecosystem, handling variable daily deliveries like milk alongside fixed monthly bills.

### 🎯 Built to help you:
* 📊 **Visualize** financial trends through interactive charts.
* 🥛 **Manage** daily milk deliveries with an automated calendar logic.
* 💸 **Track** and categorize everyday expenses (Groceries, Rent, Bills).
* 📑 **Generate** reports for customized time periods.
* 💾 **Secure** your data with Cloud Backup to Google Drive.

## 🚀 Key Features

| Feature | Description |
| :--- | :--- |
| 🏠 **Smart Dashboard** | Real-time overview of total spend, categorical distribution, and unpaid dues. |
| 🥛 **Milk Calendar** | Color-coded status tracking (Taken, Paid, Unpaid) with auto-calculated billing. |
| 📈 **Deep Analytics** | Dynamic line & bar charts showing historical spending trends. |
| 💳 **Expense Manager** | Chronological feed of all transactions with easy filtering and editing. |
| 🌙 **Theme Support** | Fully adaptive, visually optimized Light and Dark modes. |
| 💾 **Cloud Backup** | Backup and restore your financial records using personal Google Drive. |
| ⚙️ **Custom Utilities** | Configure custom milk rates, default quantities, and dynamic reminders. |

## 🛠️ Tech Stack

* **Language:** Java / Kotlin
* **Architecture:** MVVM (Model-View-ViewModel)
* **Database:** Room Persistence Library (SQLite)
* **UI Components:** Material Design 3, ViewBinding, CoordinatorLayout
* **Data Handling:** LiveData & Coroutines for reactive state management
* **Charts:** MPAndroidChart for custom financial visualization

## ⚡ Getting Started

### Prerequisites
* Android Studio (Ladybug or newer recommended)
* Android SDK 24+ (Android 7.0 Nougat minimum)
* Gradle 8.0+

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/DEVS-shakti/HISAAB.git](https://github.com/DEVS-shakti/HISAAB.git)


(i).Open in Android Studio:

      Launch Android Studio and choose Open.
      
      Navigate to the cloned HISAAB folder.
      
      Allow Gradle to complete the sync process.

(ii).Run the App:

      Connect an Android device or launch an Emulator.

      Click the Run ▶ button or press Shift + F10.
